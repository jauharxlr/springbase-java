Atomic Transactions Deep-Dive

The `/rest/v1/actions/execute` endpoint executes multiple operations in a single database transaction. If any step fails, the entire batch is rolled back automatically.

Example 1: Bank Transfer

Validate balance, then move funds between two wallets.

{ "operations": [ { "op": "PRE_CONDITION", "table": "wallets", "filters": {"id": "eq.A"}, "condition": "balance >= 50" }, { "op": "UPDATE", "table": "wallets", "data": {"balance": -50}, "filters": {"id": "eq.A"} }, { "op": "UPDATE", "table": "wallets", "data": {"balance": 50}, "filters": {"id": "eq.B"} } ] }

Example 2: E-commerce Checkout

Reduce inventory and create order in one atomic step.

{ "operations": [ { "op": "UPDATE", "table": "stock", "data": {"qty": -1}, "filters": {"sku": "eq.MAC-M3"} }, { "op": "INSERT", "table": "orders", "data": {"sku": "MAC-M3", "price": 1999} } ] }

Secure Isolation

The owner_id column in storage tables is auto-managed. Users can only delete or overwrite their own files unless the bucket is public.

AI-First Migration Guide

Don't write schemas manually. Use LLMs to generate the JSON required for the /admin/v1/tables endpoint.

Prompt Example:

"Generate a JSON schema for a 'ride-sharing' app with rides, drivers, and payments. Include stakeholder columns for RLS. Use the SpringBase format: { name, columns: [{name, type, stakeholder}] }"

Supported: GPT-4o, Claude 3.5

Merchant-Customer Visibility Example

In a marketplace, an 'order' needs to be visible to both the person who bought it and the merchant who sells it.

The Setup:

Create an orders table with:

  • user_id (Customer)
  • merchant_id (Seller)
  • Mark both as Stakeholder in Editor.

The Customer sees it because they match user_id. The Merchant sees it because they match merchant_id.

-- API usage is identical for both parties -- The engine handles the heavy lifting GET /rest/v1/orders -- Result for Customer A: -- [{ "id": 1, "user_id": "A", "merchant_id": "B", ... }] -- Result for Merchant B: -- [{ "id": 1, "user_id": "A", "merchant_id": "B", ... }]
